# Go-No-Go-HW7-
Code and instructions for a go no go food-based task run on PsychoPy.

To run it - download Go No Go folder
  Inside this folder is stimuli (images) folder.
  The csv file with repsonses will save here.
  _Update the file paths within the code to your desired location._

**Overview:**
Food is separated into high fat (HF) and low fat (LF) foods.

LF is the 'go' condition while HF is the 'nogo' condition.

Each trial is randomized.

Response, reaction time, and if the response is correct is recorded into csv file at the end of each trial.
